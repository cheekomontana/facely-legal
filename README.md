# Facely — legal pages

Published source for the Facely app's [Privacy Policy](https://cheekomontana.github.io/facely-legal/privacy.html)
and [Terms of Service](https://cheekomontana.github.io/facely-legal/terms.html), served with GitHub Pages.

This repository contains only these documents. The Facely application source is private.

Canonical copies live in the app repository under `legal/`; changes should be made there and mirrored here.
